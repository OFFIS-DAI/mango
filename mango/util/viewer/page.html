Arrow keys move, Enter selects, ? lists all keys

Keyboard shortcuts

Anywhere

/
focus the filter
v
Records / Lanes
e E
next / previous failure
[ ]
go to the cause / the first effect
f
follow the selection's chain in Lanes
t
go to a time
g G
focus the map / widen it
Esc
close, then clear the selection
?
this sheet

Records

↑ ↓
move the cursor row
Home End PgUp PgDn
jump
Enter Space
select or deselect

Lanes

↑ ↓
previous / next record in the lane
← →
nearest record in the next lane
Home End PgUp PgDn
jump within the lane
Enter Space
select or deselect
a
choose lanes
o
Packed / File order
z
Fit all lanes
x
stop following the cursor's lane
Alt+← →
move the cursor's lane

Map

arrows
nearest agent in that direction
Home
the hub
Enter
filter or follow; on a connection: show its messages
Shift+Enter
follow the agent and its partners
c C
next / previous connection
Esc
back to the agent, then to the view
